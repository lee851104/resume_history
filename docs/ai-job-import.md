# AI 職缺列表匯入

在網站選擇「職缺待辦」→「匯入職缺」，按「複製給 AI 的整理指令」，交給平常使用的 AI。將它回傳的 JSON 貼回網站，預覽後勾選匯入。

## 固定格式

以下連結為格式範例，請換成實際職缺連結。

```json
[
  {
    "jobUrl": "https://example.com/jobs/123",
    "company": "公司名稱",
    "title": "Python 工程師",
    "notes": "工作地點、薪資、推薦原因及查詢日期；未確認資訊請註明"
  }
]
```

- `jobUrl` 必填：完整的 HTTP 或 HTTPS 職缺連結，不含帳號密碼。
- `company`、`title`、`notes` 選填：可省略、填空字串或 `null`。
- 每次 1～200 筆；貼上的文字最多 1,000,000 字元。只使用這四個欄位，額外資訊放進 notes。
- 支援完整 JSON 陣列，也可包含外層 Markdown 的 json 程式碼區塊。
- 預覽會逐筆標出無效資料與重複網址；可以只勾選要匯入的有效職缺。
- 比對重複網址時會忽略 utm_*、fbclid、gclid、msclkid 追蹤參數，保留其他參數與 hash，避免混淆不同職缺。保存的網址不會被改寫。

## 待辦流程

匯入後預設為「待評估」，可切換「準備投遞」「暫緩」「不考慮」，也可編輯連結、公司、職稱與備註。

真正投遞後按「記錄已投遞」，選擇當次履歷與投遞日期。原待辦連到新建立的投遞紀錄，後續在投遞總覽更新面試、錄取等進度。此按鈕記錄已完成的投遞，不會代替使用者送出履歷。

待辦不計入已投遞統計。資料沿用既有端對端加密，匯入解析、網址去重與資料驗證都在瀏覽器完成，不需新增 AI API 金鑰或資料庫 migration。

## 舊資料相容

舊快照沒有 prospects 欄位時，自動視為空待辦。新增欄位後，舊版程式會拒絕未知欄位，避免舊版儲存時抹掉待辦；更新後若仍有舊分頁，請重新整理再解鎖。
